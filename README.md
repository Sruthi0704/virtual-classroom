# Virtual Classroom

A web-based virtual classroom platform developed for online learning, examinations, and academic management.

The platform enables faculties and students to interact through a centralized system for assignments, online tests, attendance, notes sharing, and performance tracking.

---

# Features

## Faculty Features
- Create and schedule MCQ and theory-based tests
- Manage assignments and submissions
- Share study materials and announcements
- Track student attendance and performance
- Evaluate theory tests and assignments

## Student Features
- Receive test and assignment notifications
- Attend online examinations during scheduled time
- View results and performance history
- Access notes and announcements
- Participate in digital classroom activities

## System Features
- Online examination management
- Assignment submission system
- Performance analytics
- Email notification support
- Responsive web interface
- ML-based online test proctoring support

# How to Run

## Frontend Setup

Install dependencies:

```bash
npm install
```

Run Angular application:

```bash
ng serve -o
```

---

## Backend Setup

Run Spring Boot application:

```bash
mvn spring-boot:run
```
